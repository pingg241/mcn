# 功能总结

按《核脉冲多道分析器顶层设计》实现：FPGA 做实时脉冲处理，通过 UDP 把事件流送给终端；终端（STM32H743 + 屏，
或笔记本上的 mca_host）做能谱、分析、显示和存储。构建、烧写、使用见 [README](../README.md)，包格式和寄存器见
[protocol.md](protocol.md)，顶层连线图见 [mca_block.pdf](mca_block.pdf)。

```
探测器/前放 → AD9280（8 bit，32 MSPS）→ FPGA：滤波、判别、计数 ──UDP──→ 终端：能谱、寻峰、刻度、显示、存储
                                                        ↑ 命令 / 心跳 / 波形
```

## 1. FPGA 前端（`fpga/`，xc7a35t，正点原子达芬奇Pro）

**顶层**：Vivado Block Design `mca_block`，由 `scripts/block_design.tcl` 生成，各方块直接引用 `rtl/` 的模块。

| 模块 | 功能 |
|------|------|
| `clk_gen` | 50 MHz 输入。MMCM 出 125 MHz（以太网）、125 MHz/90°（RGMII TXC）、200 MHz（IDELAYCTRL）；PLL 出 32 MHz 采样时钟和相位可调的 ad_clk |
| Processor System Reset ×2 | 复位键 + 时钟锁定 → 以太网域、ADC 域各一个同步复位 |
| `phy_rst` | 复位释放后再保持 20 ms 才放开 PHY 复位 |
| `led_drv` | LED0 心跳闪烁，LED1 链路，LED2 RUN，LED3 事件（展宽约 30 ms） |
| `adc_if` | ODDR 转发 ad_clk，IOB 寄存器采 8 位数据和 OTR |
| `adc_domain` | ADC 时钟域总成：配置锁存、与以太网域握手、测试源/ADC 选择、脉冲处理、计数快照、波形捕获 |
| `pulse_proc` | 数字脉冲处理（见下） |
| `test_pulser` | 片内测试脉冲源（见下） |
| `wave_capture` | 4096×16 环形缓冲，按触发捕获波形 |
| `async_fifo` | 事件 FIFO：1024 × 72 位，跨 ADC → 以太网时钟域 |
| `rgmii_if` | RGMII 物理接口，1000/100/10 Mbps |
| `eth_rx_parser` / `eth_tx_engine` | 硬件以太网收发：ARP + IPv4 + UDP |
| `mcev_packer` | 事件打包 |
| `eth_core` | 以太网域总控：寄存器、命令、主机学习、心跳、发送仲裁 |

**脉冲处理**（`pulse_proc`，每拍一个采样，全流水线）：
- 输入：极性校正，ADC 饱和（OTR）检测。
- 快滤波（长度、间隔可调）过阈触发，触发拍作为 48 位时间戳（前沿）。
- 慢滤波：Jordanov 梯形成形 + 极零补偿（`PZ_M` 由前放衰减时间常数算出），平顶高度即脉冲幅度。
- 基线恢复（BLR）：空闲期跟踪基线，时间常数 2^n 拍，触发后冻结一段时间。
- 能量 `E = ((H >>> S) × G) >> 14`：在峰值窗内取最大值，或取窗口中点定点采样（`PEAK_FIXED`）。
- 堆积判别：窗 W 内有两个触发，或过阈时间超过 `TOT_MAX`，都标为堆积；可选择丢弃堆积事件（`PU_DISCARD`）。
- 输入基线越出允许范围时标记，并 INHIBIT。
- 改滤波参数后自动冲刷滤波器（约 130 µs），稳定前不出事件。
- 死时间计账：`busy_ticks` = 每个触发 [t−W, t+W] 的并集，INHIBIT 期间也计入。所以 `活时间 = total_ticks − busy_ticks`，
  干净计数 / 活时间就是无偏计数率。
- 计数器：触发总数、堆积数、FIFO 满丢弃数、饱和数、实时间拍数、死时间拍数。

**测试脉冲源**（`test_pulser`）：每拍做一次伯努利试验（近似泊松到达），计数率可设；脉冲为单极点指数衰减，
可加一阶上升沿和均匀噪声；幅度有三种模式：定幅、峰 + 平台、均匀分布；基线可设。不接探测器也能测完整条链路。

**波形捕获**：信号源有 4 种（原始 ADC、极性校正后、快滤波、慢滤波）；深度 256~4096 点；触发前点数可设；
可以不等触发立即捕获。捕获结果分成每包 ≤ 256 点的 MCWF 包发出。

**以太网**：
- RGMII：测 RXC 频率自动识别速率；RX 用 IDELAY 调采样点；TXC 由 ODDR 产生，可相移 90°。
- 收：识别发给本机的 ARP 请求和 UDP 5000 端口的命令，CRC 正确才处理；统计收帧数、CRC 错帧数。
- 发：硬件算 IP/UDP 校验和、补齐最短帧、加 FCS；ARP 应答。
- 主机学习：最后一个发合法命令的地址就是主机，事件和心跳都发给它；`HOST_LOCK` 可锁定主机。
  默认 IP 192.168.1.10，可用 `SET_NET` 在运行时改 IP/MAC。
- 事件打包：每包 1~64 个事件；攒满、超时或时间戳高位变化时发包。
- 心跳 1 Hz：各计数器、实/死时间、状态位，以及下一个事件包的序号（终端靠它查丢包）。

**命令与寄存器**：9 条命令（PING、读写寄存器、清计数、设打包参数、抓波形、读状态、复位、设网络），
24 个配置寄存器带范围检查（越界应答 BAD_VALUE），另有只读计数/状态寄存器。

**工程**：`build.tcl` 一条命令出位流（`build/mca.bit`、`build/mca.bin`，随仓库提交），资源 LUT 20%、FF 5749、
BRAM 5.5、DSP 7；时序收敛（WNS +0.221 ns，WHS +0.036 ns）。

## 2. 通信协议

全部大端，详见 [protocol.md](protocol.md)：

| 端口 | 包 |
|------|----|
| UDP 5000 | MCCM 命令（16 B）→ FPGA；MCRS 应答（16 B）、MCST 心跳（64 B，1 Hz）← FPGA |
| UDP 5001 | MCEV 事件流（16 + 8n B）、MCWF 波形 ← FPGA |
| UDP 6000 | 终端的文本控制台（本工程扩展） |

协议在三处实现且一致：`fpga/rtl/mca_regs.vh`、`mcu/app/mca_proto.h`、`tools/mcaproto.py`。

## 3. 终端应用（`mcu/app/`，与硬件无关）

同一套代码既编进 STM32 固件，也编进 PC 宿主版。硬件相关的只有 `platform.h` 里的接口（UDP、屏、按键、存储、时钟、日志）。

| 模块 | 功能 |
|------|------|
| `fpga_link` | FPGA 连接状态机：发现（每 500 ms PING）→ 下发配置 → 运行。命令队列带序号，超时 100 ms 重发、3 次失败报错；3.5 s 收不到心跳就重新发现 |
| `acq` | 事件进谱（堆积事件可选进不进谱），统计四种事件标志。按包序号空洞和心跳的 `pkt_seq` 查丢包和重复包。用心跳算实时间、活时间、死时间%、ICR、OCR、死时间校正计数率 |
| 丢失补偿 | 应发事件数（心跳触发总数，丢弃堆积时减去堆积数）÷ 实收事件数 = 补偿系数，用来补偿 FIFO 满丢弃和 UDP 丢包；计数在心跳时刻对齐 |
| `spectrum` | 直方图 256~8192 道（2 的幂），`道址 = E >> 移位`，超出道数单独计数；对数/线性显示 |
| `peak` | 寻峰：SNIP 估本底 → 平滑 → 局部极大且显著 → 爬到半高区内的峰顶 → 去重 → 高斯 + 线性本底做 Levenberg-Marquardt 拟合 → 校验（面积 > 3σ、宽度合理、峰位在区间内）。最多 8 个峰，按面积排序，给出峰位、FWHM、净面积 ± 误差、χ²/ndf、能量、分辨率。采集中每 2 s 自动重算 |
| 能量刻度 | `cal`：1 点比例、2 点线性、3 点以上二次（最小二乘）；`calpk`：把能量按顺序对给最大的几个峰 |
| `filter_cfg` | 物理参数（τ、上升/平顶时间、快滤波长度/间隔、阈值）换算成 FPGA 寄存器，和 `mcaproto.py` 结果一致（有单元测试对照） |
| `wave` | 请求波形、重组分包，等不到触发时报超时 |
| `settings` | 配置项（网络地址、滤波参数、极性、堆积处理、测试源、道数、打包参数、刻度等），带范围检查和 CRC，存在槽 0；`set` 后自动重新下发 FPGA |
| `store` | 7 个能谱存储槽：谱、心跳统计、刻度、名字一起存；调出后冻结显示，`start` 恢复采集 |
| `ui` / `gfx` | 480×320 RGB565，三页（见下），字体由 `mcu/tools/gen_font.py` 生成 |
| `console` | 文本控制台（见下） |

**界面三页**（KEY 短按切页，长按 1 s 清谱，在波形页长按换信号源）：
- **能谱**：对数/线性坐标，标出峰；刻度后横轴显示能量；底部列出面积最大的两个峰。
- **波形**：每秒自动抓一次，没有触发就强制抓一段基线；横轴是 µs，0 点在触发处；每列取 min/max，压缩显示时不丢尖峰。
- **统计**：实/活时间、ICR/OCR、校正计数率、丢包与补偿、当前配置、峰表。
- **状态栏**（三页共用）：状态（RUN / STOP / CONFIG / NO FPGA / RECALL）、实时间、活时间、死时间%（按高低变色）、ICR、谱计数、本机网口速率。

**控制台命令**：`status`、`start [活时间]`、`stop`、`clear`、`get`、`set`、`dump`、`save`、`defaults`、`spec`（读谱）、`peaks`、
`cal`、`calpk`、`cal off`、`wave`、`store`、`recall`、`slots`、`reg`（透传读写 FPGA 寄存器）、`reconfig`、`log`。
可以从 UDP 6000 远程调用（多行命令，长回复自动分包）；宿主版也可以直接在它的命令行窗口里输入。

## 4. 运行平台

**STM32H743 固件**（`mcu/port/stm32h7/`）：
- 400 MHz 主频，配好 MPU 和缓存：以太网缓冲放在不可缓存的 SRAM2，内存按区分配（帧缓冲、栈、寻峰工作区、LwIP）。
- LAN8720 RMII + LwIP UDP；PHY 寄存器按通用标准访问，PHY 地址自动扫描。
- ST7796S 4.0" 屏：SPI4 40 MHz，DMA 按 32 行分块刷新；默认开反显（按 IPS 屏）。
- 存储：内部闪存 Bank 2 的 8 个 128 KB 扇区（槽 0 存配置，槽 1~7 存能谱）。
- 其他：USART1 115200 输出日志；按键、LED 和引脚定义集中在 `board.h`。
- 固件大小约 116 KB。

**PC 宿主版 mca_host**（`mcu/port/host/`，笔记本代替 STM32）：
- 跑同一套 `app/` 代码，用真实 UDP 和 FPGA 通信，FPGA 侧不用改。
- 窗口：Windows 用 Win32，Linux / WSL 用 X11（WSLg）。按屏幕自动取最大整数倍缩放，可拉伸。
  空格、回车或鼠标左键当作 KEY。
- 控制台：直接在它的命令行窗口输入命令，`quit` 退出。
- 存储：存成当前目录 `host_nv/` 下的文件。
- 参数：`--fpga`、`--local`、`--nv`、`--no-window`，测试用的 `--seconds`、`--bmp`（退出时截三页图）、`--key-at`（模拟按键）。
- 默认绑定所有网卡，按路由自动找本机地址；UDP 接收缓冲过小时给出提示。

## 5. PC 工具（`tools/`）

- `mca_tool.py`：
  - 直连 FPGA：`ping`、`status`、`read`、`write`、`setup`（按物理参数配置）、`run`（采谱存 CSV、可画图）、`wave`、`listen`。
  - `fake-fpga`：假 FPGA。合成 NaI 能谱（Cs-137、Co-60、K-40、Ba-K + 本底），计数率可设，可模拟 UDP 丢包；
    会应答命令、发心跳和波形，没有板子也能调终端。
  - `mcu`、`mcu-spec`：远程调用终端控制台，下载能谱为 CSV。
- `mcaproto.py`：Python 版协议（打包/解包、寄存器表、`filter_params()`）。

## 7. 构建与依赖

- 终端：xmake。宿主版 `-p mingw`（Windows）或 `-p linux`；固件 `-p cross --toolchain=gnu-rm`。
- STM32 第三方库：`mcu/scripts/fetch_deps.py` 按固定版本拉取 ST HAL、CMSIS、LwIP，不放进仓库。
- FPGA：Vivado 2023.2。`block_design.tcl` 建工程，`build.tcl` 出位流，`sim/run_sim.py` 跑仿真。
- 克隆后要装什么、`--mingw` / `--sdk` 怎么填，见 README"拿到代码之后"。
